초록 칸

    기기 연결 설정

    기본값: 같은 기기 여러 탭. 같은 브라우저의 같은 주소를 여러 탭에서 열어 방을 시험해요. 혼자 연습은 방이 필요 없어요.

    여러 아이패드·PC 연결: 인터넷이 연결된 상태에서 아래 설정을 한 번 준비해 주세요. 파일 앱 미리보기 대신 HTTPS로 올린 게임 주소를 Safari 또는 PC 브라우저에서 열어요.

    1. Firebase Console에서 프로젝트와 웹 앱을 만들고, Authentication → 로그인 방법 → 익명을 켜요.
    2. Realtime Database를 만들고 아래 규칙 전체를 규칙 탭에 붙여넣어 게시해요. 전용 테스트 프로젝트를 사용하세요.
    3. 웹 앱 설정의 firebaseConfig를 JSON(키와 문자열을 큰따옴표로)으로 넣어요. Realtime Database 화면의 databaseURL도 넣어 주세요.
    4. 저장 후 연결 주소 복사로 같은 설정을 친구 기기에 보내요. 각 기기에서 그 주소를 열고, 선생님의 4자리 방 번호로 입장해요.

    웹 앱 구성에는 공개 클라이언트 설정만 넣으세요. 서비스 계정이나 비밀번호는 넣지 마세요. 공개 수업이 끝나면 전용 프로젝트에서 게임 데이터를 정리하세요. 순위는 활동용이며 점수의 부정 조작을 검증하는 서버는 아니에요.
